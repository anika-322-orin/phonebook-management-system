# Phonebook Management System

A console-based contact management application developed in C, demonstrating the practical implementation of Data Structures and Algorithms.

## Features

- Add, display, update and delete contacts
- Sort contacts alphabetically using Merge Sort
- Search contacts by name using Binary Search
- Search by phone number or email using Linear Search
- Duplicate contact detection
- Basic phone number and email validation
- Interactive menu-driven interface

## Technologies Used

- C Programming
- Structures and Arrays
- Data Structures and Algorithms
- String Manipulation

## Algorithms Implemented

| Algorithm | Purpose | Time Complexity |
|---|---|---|
| Merge Sort | Sorting contacts | O(n log n) |
| Binary Search | Searching sorted contacts by name | O(log n) |
| Linear Search | Searching by phone or email | O(n) |

## Project Objective

To apply fundamental programming concepts and searching and sorting algorithms to a practical contact management application.

## Current Limitations

- Contacts are stored in memory during execution.
- Maximum capacity is 100 contacts.
- Input validation requires further refinement.

## Future Improvements

- Permanent file-based storage
- Improved input validation
- Graphical user interface
